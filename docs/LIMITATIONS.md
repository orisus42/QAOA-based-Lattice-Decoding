# Interpretation and limitations

1. **Toy scale.** The main family uses 16 qubits and an eight-dimensional augmented lattice. Exhaustive reference calculations are deliberately feasible. These experiments do not demonstrate an attack on deployed ML-KEM or a quantum speedup over classical cryptanalysis.
2. **Classical controls matter.** Two-coordinate refinement solves 497/512 cases in the main simulation cohort and all eight selected hardware cases. Cheap incumbent-informed pruning attains more selected hardware optima than the cached method and is far cheaper to select. The contribution is sparse-versus-full QAOA resource reduction and an implementation speedup of the original expensive selector.
3. **Caching is not a new pruning principle.** It preserves an existing rule's decisions. Phase sparsification and analytic p=1 expectations have prior art. Algorithmic novelty and scaling improvements remain unestablished.
4. **75% is not universally optimal.** It is a development-selected, subsequently frozen comparison. Finer sweeps, alternate budgets, and shot counts change the tradeoff. Later exploratory use of an old cohort does not restore its holdout status.
5. **Bounded search.** The bit encoding covers a small neighborhood around Babai. Coverage, CVP success, and planted-secret recovery are reported separately. The norm objective is not the exact centered-binomial likelihood.
6. **Noise models are predictions.** Routing and noise snapshots correspond to particular calibration data. Finite Monte Carlo trajectories introduce uncertainty. The smooth shot-response figure evaluates an analytic expression at 400 budgets; it is not 400 independent experiments. Saved simulation-to-hardware mismatch is retained.
7. **Hardware selection.** Six examples were drawn from known Babai failures, with two sentinels. Eight-case success fractions cannot be generalized to random Module-LWE instances. Two jobs on one device are not evidence of broad device-to-device robustness.
8. **Precision extension.** The second hardware run followed the initial result. Its fixed extension plan is preserved. First-run results remain separate; pooled results are descriptive, not a new preregistered population test.
9. **Rare events.** Full QAOA produced only four improving samples across the six difficult cases. A zero observed count does not prove zero probability. Fixed-cohort bootstrap intervals can understate uncertainty at zero cells; conservative exact simultaneous bounds include zero for the average improvement. A supplemental stratified exact test was added after observing initial data and tests a different conditional null. Do not substitute it for the original primary interval.
10. **Independence assumptions.** Binomial/shot intervals assume independent, stationary shots. Ordered samples and block counts permit a limited drift check, not a proof of those assumptions.
11. **Runtime scope.** The 14.02x timing result concerns selector CPU work in one environment, including cache construction, with precomputed h/J. It excludes common preprocessing, parameter training, circuit construction, routing, queueing, and quantum execution.
12. **Numerical diagnostics.** Two early EXP-012 attempts failed because of a reproduced Kraus-fusion normalization problem. The successful run restricted fusion to one qubit; failed-run summaries and DIAG-013 remain in the archive. Outputs were not silently renormalized.

No new hardware measurements or scientific experiments were performed for repository publication. Release checks revalidate saved evidence and exercise existing code. See [archive boundaries](REPRODUCIBILITY.md#archive-boundaries) for omitted derived intermediates and privacy-related exclusions.
