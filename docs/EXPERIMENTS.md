## How to read a run

`config.json` / `frozen_protocol.json`: parameters, seed, selection and evaluation policy.  
`manifest.json`: environment, source and output hashes.  
`instances.json`: generated public data and evaluation-only reference fields.  
`per_instance.json` / analysis folders: metrics, uncertainties, decisions and timings.  
`source/`: historical implementation snapshots.  
`counts/`, `circuits/` in hardware runs: measured data and exact circuit representations.

The [method](METHOD.md), [results map](RESULTS.md), and [reproduction guide](REPRODUCIBILITY.md) identify the primary studies. Historical notes in `project/methodology*.txt` reflect the state at the time they were written and may describe plans later completed.
